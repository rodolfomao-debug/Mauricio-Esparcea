Inicio Rápido

Instalación en cuestión de segundos

Puedes añadir la dependencia a tu proyecto utilizando cualquiera de los gestores de paquetes más populares. Simplemente ejecuta el comando y empieza a importar los módulos.

1

Instala la dependencia

Selecciona tu gestor preferido (npm, yarn, pnpm).

2

Inicializa el cliente

Configura tus credenciales y opciones globales.

3

¡Empieza a construir!

Accede a la API completa y componentes reactivos.

bash / terminal
# Instalación vía npm
npm install devnexus-core
# Ejemplo de Uso (index.ts) 
import { DevNexus } from 'devnexus-core';

// Inicializar el cliente
const app = new DevNexus({
  apiKey: process.env.NEXUS_KEY,
  theme: 'dark'
});

// Ejecutar tarea de ejemplo
await app.connect();
console.log('¡Conectado exitosamente!');
